# This is why I started PersonaKit

*Posted in September 2026, before PersonaKit was released. PersonaKit is now open source and free to use: [personakit.me](https://personakit.me), docs at [personakit.me/docs](https://personakit.me/docs).*

AI is beginning to remember us. I believe the important question isn’t just how good that memory becomes, but who controls it.

We think the answer should be simple: you do.

Your AI’s memory. Your say.

We’re starting a small private pilot. Would love to hear what you think 👇

We started PersonaKit because AI memory is crossing a line.

For a long time, every assistant began from zero. That was annoying, but at least it was clear. You knew the model did not know you.

Now assistants are starting to remember. That is useful. It is also a trust problem.

A memory can be wrong.
A memory can be old.
A memory can belong in one conversation and not another.
A memory can be true, but still too private to carry everywhere.

The answer cannot be: trust the model to decide what it knows about you.

We think personal AI memory should belong to the person.

You should be able to inspect it.
You should be able to see where it came from.
You should be able to correct it.
You should be able to restrict it.
You should be able to take it with you when you move between assistants.

That is what we are building with PersonaKit.

Not another chatbot.
Not a vague second brain.
Not a memory box the model fills on your behalf.

A source-backed memory layer for the assistants people already use.

The first version is intentionally small: bring one source, review the memories, connect one assistant, and test whether the assistant understands you better without getting more authority than you gave it.

The product thesis is simple:

Your AI's memory. Your say.

We are preparing a small private pilot.

If this feels familiar, join the waitlist at https://personakit.me/. We will start with a few early users and reach out directly.
