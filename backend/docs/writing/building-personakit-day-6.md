# Building PersonaKit: Day 6

The most underrated feature in AI memory might be restraint.

Not remembering more.

Not retrieving more.

Knowing when memory should stay out of the answer.

One of the hardest answers for an AI memory product is:

“I don’t have anything relevant here.”

Most memory products naturally pull in the other direction.

Remember more.
Use more context.
Make every answer feel more personal.

But I think that is only half of the problem.

The other half is knowing when not to use memory.

Because personal memory is powerful exactly because it can shape the answer.

It can change what the assistant assumes.
It can change the tone.
It can change the recommendation.
It can make the answer feel more specific, more useful, more “you.”

But that also means it can be wrong in a very personal way.

A memory can be true, but irrelevant.
Useful once, but stale now.
Important in one context, but noisy in another.
Technically available, but better left outside the answer.

That is the part I keep coming back to with PersonaKit.

The goal is not to make an assistant use memory all the time.

The goal is to make memory earn its place.

Sometimes that means bringing in the right context.
Sometimes it means showing the source.
Sometimes it means respecting a boundary.

And sometimes it means saying:

Nothing relevant here.

No forced personalization.
No confident overreach.
No memory just because memory exists.

That answer sounds boring.

But in a personal AI system, boring can be a trust feature.

If memory is going to influence how assistants understand us, then the absence of memory has to be a first-class behavior too.

Not every answer needs your history.

Sometimes the best product decision is to leave the person alone.
