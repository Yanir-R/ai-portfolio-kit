# Meta’s new WhatsApp Business MCP is a good example of where MCP starts to make sense.

It is not just “let an agent call an API.”

It gives an agent an operational surface:

find the business account,
check the number,
create a template,
configure webhooks,
send a test message,
surface what prerequisite is missing.

That workflow used to be split between dashboards, docs, API calls, tokens, and trial-and-error.

Now it can start becoming something an agent can operate directly.

That matters.

MCP had the normal hype cycle.

First it was “every product needs an MCP server.”

Then came the backlash:
too many tools,
bad setup,
weird errors,
too much context,
not enough trust.

Fair.

But releases like this make the useful shape clearer.

And with WhatsApp, the details matter a lot.

This is not a harmless demo tool.

It can message real people.

So OAuth, scopes, logs, confirmation before sending, and separating read access from manage access are not boring implementation details.

That is the difference between a useful agent workflow and a very expensive mistake.

Not more tools in the prompt.

Safer ways for agents to operate real systems.
