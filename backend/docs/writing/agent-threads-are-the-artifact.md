# I like the direction Delta by Zed Industries is taking.

Not because it is another place to run coding agents.

Because it starts from a problem I keep feeling lately:

with agent-written code, the diff is not enough anymore.

The important context is in the path that produced it.

What was asked.
What the agent assumed.
Where a human pushed back.
What got tested.
Why this version was accepted.

If that path disappears, review gets much harder.

That matters even more on a team.

A teammate should be able to join the same thread, see the code and the conversation together, comment in place, and continue from there.

The agent thread should not be a disposable transcript.

It should become part of the work artifact.

What they’re building:
https://delta.dev/
