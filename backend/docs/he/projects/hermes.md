# Hermes

## Overview
הסוכן שלי שפועל כל הזמן. הוא רץ כל היום על המחשב שלי, שומר את הזיכרון שלו ב-Obsidian ומגיע אליי דרך טלגרם. הוא בנוי על Hermes Agent, פרויקט קוד פתוח של Nous Research, ורץ כהפצה פרטית עם קבוצה קטנה ומוגדרת של שינויים שלי. סביבו בניתי את החלקים שהופכים סוכן שפועל כל הזמן לכזה שאפשר לסמוך עליו: צינור זיכרון, יומן למידה וביקורת לילית. המאגרים פרטיים.

## Technical Details
- **Base**: Hermes Agent (קוד פתוח, של Nous Research), הפצה פרטית
- **Memory**: Obsidian vault תחת git
- **Interface**: טלגרם
- **Language**: Python ו-shell
- **Models**: Claude קודם, Codex כגיבוי כשהמכסה נגמרת

## Key Features
- זיכרון בשלושה צעדים: hook רושם כל סשן שהסתיים בכ-10 אלפיות שנייה בלי קריאה למודל, ריצה לילית קוראת את הראיות של היום ומעדכנת את הדפים המסודרים, והתוצאה היא commit אחד שאדם יכול לבדוק
- הריצה הלילית חייבת להצהיר אילו מקורות כיסתה ואילו דפים שינתה, והקוד בודק את ההצהרה לפני שהריצה נחשבת
- יומן משימות שומר סיכומים קצרים ומצונזרים של עבודה שהושלמה והופך דפוסים חוזרים להצעות עם ראיות. הוא אף פעם לא מקדם לבד skill, hook או זיכרון; אדם מאשר
- דפוס נספר רק כשהוא מופיע בשני ימים שונים, או שלוש פעמים ביום אחד
- מה שרץ בפועל תמיד שווה ל-commit מתויג, ושינויים מהפרויקט המקורי נכנסים רק דרך בקשת מיזוג שנבדקה
