# Trinity Legal

## Overview
מערכת לניהול מסמכים ותיקים שנבנתה בהתאמה אישית למשרד עורכי דין קטן שמתמחה בנדל"ן ומקרקעין. האפיון נעשה בישיבות עם עורכי דין שמתמחים בתחום, כך שהתהליך במערכת תואם את הדרישות ואת הצורך של המשרד, ולא תבנית כללית. התוצאה היא מערכת ייחודית שמותאמת למגזר מסוים. היא רצה בענן, בעברית ומימין לשמאל, ונמצאת בפיילוט חי עם לקוחות פעילים.

מתוך העבודה הזו אני מציע היום מערכת מותאמת מאותו סוג גם למשרדים קטנים אחרים: משרדי עורכי דין, רואי חשבון ומשרדים מקצועיים דומים.

בשלב הזה זו עבודת מוצר פול סטאק, ועדיין לא עבודת AI, וזה מכוון. כך אני בונה: קודם מערכת שעובדת, מוודאים שהיא אמינה ושהיא עונה על הצרכים והרצונות של המשרד, ורק אחר כך מוסיפים AI על בסיס שכבר הוכיח את עצמו. המערכת נותנת מענה לכאבים שמשרדים קטנים רבים מכירים: מסמכים שמפוזרים בין מחשבים ומיילים, קושי לדעת מהי הגרסה העדכנית, עבודה משותפת על אותו מסמך, ומידע שצריך להישאר שמור ומסודר לאורך שנים.

## Technical Details
- **Frontend**: Next.js 16, React 19, TypeScript
- **Backend**: Fastify 5, TypeScript
- **Database**: PostgreSQL 16 עם row-level security
- **Desktop**: תוסף .NET 10 ל-Word ול-Excel ב-Windows
- **Cloud Platform**: Google Cloud - Cloud Run, Cloud SQL, Cloud Storage, Pub/Sub, Cloud Scheduler, Firebase Hosting
- **CI/CD**: GitHub Actions, סריקת סודות, ובדיקת קוד עם AI על כל בקשת מיזוג

## יכולות עיקריות
- כמה אנשים יכולים לעבוד על אותו מסמך Word בלי לאבד גרסה: עריכה נעשית בהשאלה, שמירה נבדקת מול הגרסה שממנה התחילה, וגרסאות שמורות לא נכתבות מחדש
- כל משרד רואה רק את הנתונים שלו. המשרד נלקח מהסשן, נאכף במסד הנתונים בכל נתיב, ונבדק לכל נקודת קצה
- כל קובץ שמועלה נסרק לנוזקות לפני שמישהו יכול לפתוח אותו
- ארכיון קיים של 56,607 קבצים (33.8 GB) יובא עם תיעוד מלא, ואדם מאשר את מה שהמייבא לא הצליח להכריע
- שש משימות מתוזמנות מטפלות בעבודת הרקע
