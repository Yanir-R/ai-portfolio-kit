# PersonaKit

## Overview
זיכרון לעוזרי AI שאפשר לקרוא, לתקן ולקחת איתך. PersonaKit קורא את השיחות שכבר יש לך עם עוזרי הקוד שלך, מציע זיכרונות קצרים ושומר את הציטוט המדויק שממנו כל זיכרון הגיע - לכל זיכרון יש קבלה. הוא מגיש זיכרונות לעוזרים דרך MCP: מאושרים, וגם לא מאושרים עם תווית שאומרת את זה. זיכרון מוגבל או בארכיון לא מוגש לעולם. אין שרת של PersonaKit ואין חשבון: הכול נשאר על המחשב שלך. אני יצרתי אותו ואני המפתח הראשי שלו, והוא קוד פתוח.

## Technical Details
- **Language**: Python 3.10+, ללא תלויות חובה
- **Storage**: SQLite מקומי
- **Interface**: שורת פקודה, שרת MCP
- **Extraction**: רץ דרך ה-CLI של Claude או Codex שאתה כבר מחובר אליו
- **License**: Apache-2.0
- **CI/CD**: GitHub Actions, בדיקות על Python 3.10 ו-3.13, רף כיסוי של 90%

## יכולות עיקריות
- כל זיכרון שומר את הציטוט שממנו הגיע, כך שאפשר לבדוק את המקור לפני שסומכים עליו
- אתם מחליטים מה כל זיכרון: לא מאושר (מוגש עם תווית), מאושר, מוגבל או בארכיון (לא מוגשים לעולם)
- סידור ודעיכה הפיכים: קודם מוצגת תוכנית, שום דבר לא משתנה בלי אישור מפורש, ואפשר לבטל צעד
- שרת MCP עם שני כלים צרים, קריאה והצעה, כך שעוזר יכול להשתמש בזיכרון שלך בלי להיות הבעלים שלו
- רק התורות שלך נשלחים למודל, והמודל רץ כשהכלים שלו כבויים

## לאן זה הולך
PersonaKit הוא הכלי הראשון בסט. היום הוא כולל ניהול זיכרון. ייבוא מ-ChatGPT, מ-claude.ai ומ-Gemini נמצא במפת הדרכים, ואני מתכנן להוסיף לצידו מערכות נוספות עם הזמן.

## מי מחליט על הזיכרון
- **אתם** יכולים לקרוא, להציע, לראות את הציטוט מאחורי כל זיכרון, לאשר, להגביל, להסתיר או לשכוח, ולסדר כפולים ומיושנים (קודם תוכנית, ואפשר לבטל כל צעד).
- **עוזר** יכול לקרוא זיכרונות שרלוונטיים לשאלה שלו ולהציע חדשים. הוא רואה ציטוט רק כשהוא שואל עליו, ולא יכול לאשר, להגביל, להסתיר, לשכוח או לסדר.

ארבעת המצבים: **לא מאושר** (ברירת המחדל, מוגש עם תווית), **מאושר** (מוגש כשרלוונטי, וחילוץ חוזר לא נוגע בהחלטה שלכם), **מוגבל** (לא מוגש לעולם) ו**בארכיון** (לא מוגש לעולם). שום דבר לא נמחק לצמיתות בלי ״שכח״ מפורש.

## איך זה בנוי
שלב הקליטה קורא את קבצי השיחה של Claude Code ו־Codex ושומר רק את מה שאתם כתבתם. שלב החילוץ נותן למודל שלכם, כשהכלים שלו כבויים, להציע זיכרונות קצרים עם ציטוט. זיכרון בלי ציטוט לא נשמר. הכול נשמר בקובץ SQLite אחד במחשב שלכם, ושם אתם עוברים עליו. שרת MCP עם שני כלים צרים, קריאה והצעה, מגיש לעוזרים שלכם (Claude Code, Codex, Trinity Agent ואחרים) רק זיכרונות רלוונטיים, ומסתיר כתובות מייל בציטוטים.
