# AI Chat Portfolio

## Overview
האתר הזה, yanirrot.com, והפרויקט שאני בונה עכשיו. מבקר שואל שאלה, וסוכן עונה בשמי רק מתוך מסמכים שאני כתבתי: הפרויקטים שלי, הפוסטים, קורות החיים ואיך אני עובד. הוא לא אומן על כלום. הקוד בוחר את המסמכים שהשאלה צריכה, המודל מקבל רק אותם, וכשהם לא מכסים את השאלה הסוכן אומר את זה ומעביר את השאלה אליי במקום לנחש. מתחת לכל תשובה יש קישור ״מאחורי התשובה״ שמראה אילו מסמכים התשובה קיבלה ומה נמדד בזמן שהיא נכתבה. האתר בעברית קודם, עם תאום מלא באנגלית, וכל דרך להגיע אליי (שיחה, מייל או וואטסאפ) נמצאת במרחק לחיצה מהצ׳אט. הקוד פתוח.

## Technical Details
- **Frontend**: React 19, TypeScript, Vite, מוגש מ־Cloudflare Pages; כל עמוד מרונדר מראש למנועי חיפוש, עם sitemap ו־llms.txt
- **Edge**: Cloudflare Worker לפני ה־API, עם Turnstile וסוד משותף, כך שאי אפשר לפנות לשרת ישירות
- **Backend**: FastAPI על Google Cloud Run, ה־API של Gemini עם מודלים חלופיים, מייל דרך SMTP, סודות ב־Secret Manager
- **Content**: תיקייה של מסמכי markdown בעברית ובאנגלית, בלי מסד נתונים
- **Search**: ביטויי ניתוב לכל מסמך, שנבדקים מול מאגר של שאלות אמיתיות בשתי השפות
- **CI/CD**: GitHub Actions, עם בדיקת קוד של AI על כל בקשת מיזוג
- **License**: MIT

## יכולות עיקריות
- עונה רק מתוך המסמכים שלי. אם שום דבר לא מתאים, הסוכן אומר את זה ומציע להעביר את השאלה אליי
- ״מאחורי התשובה״: המסמכים שהתשובה קיבלה, הטוקנים והזמן שלקח, מתוך התיעוד של התשובה עצמה
- טקסט בתוך המסמכים ובהודעה של המבקר הוא תוכן, אף פעם לא הוראה (הגנה מפני prompt injection)
- מגבלות ששומרות על התקציב: 20 תשובות למבקר ביום, 300 ביום לכל האתר, ותקרת הוצאה חודשית. כל הודעת מגבלה מובילה ליצירת קשר איתי
- מהשאלה השלישית מופיע כרטיס שמציע להמשיך איתי אישית
- קביעת שיחה (cal.com) ושליחת מייל קורות בתוך האתר, ומבקר יכול גם להשאיר כתובת מייל בצ׳אט
- שרטוטים ליד התשובה, שהקוד בוחר לפי השאלה והמסמכים, אף פעם לא המודל
