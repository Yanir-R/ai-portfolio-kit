# Trinity Agent

## Overview
העוזר האישי שלי, שפועל כל הזמן. הוא רץ כל היום על המחשב שלי, ואני מדבר איתו בצ'אט פרטי בוואטסאפ או בטלגרם, כמו שכותבים לבן אדם. הוא לומד איך אני עובד, מכין את העבודה לפני שאני מבקש, ובודק איתי רק במקומות שבאמת חשובים. לזיכרון שלו יש שתי שכבות. התיעוד שלו עצמו, כלומר סיכומי העבודה, השיפורים שהוא מציע, המדידות והביצועים, נשמר ב-Obsidian תחת git ומתעדכן לבד כל יום. PersonaKit, כלי הזיכרון שלי בקוד פתוח, מנהל את הזיכרון המשותף בין כל הסוכנים שלי לבין כלי הפיתוח כמו Claude Code, כך שכולם עובדים מאותה תמונה מאושרת. הוא בנוי על Hermes Agent, פרויקט קוד פתוח של Nous Research, ורץ כהפצה פרטית עם קבוצה קטנה ומוגדרת של שינויים שלי. יש לו אתר משלו, personakit.me/trinity, ושם הוא נמצא עכשיו בפיילוט פרטי בהזמנה. המאגרים פרטיים.

## Technical Details
- **Base**: Hermes Agent (קוד פתוח, של Nous Research), הפצה פרטית
- **Memory**: Obsidian vault תחת git לתיעוד של הסוכן עצמו (סיכומי עבודה, שיפורים, מדידות וביצועים); PersonaKit לזיכרון המשותף בין הסוכנים שלי לבין Claude Code
- **Interface**: וואטסאפ וטלגרם
- **Language**: Python ו-shell
- **Models**: OpenAI דרך Codex, או OpenRouter, לפי ההגדרה של הפרופיל

## יכולות עיקריות
- קריאה והכנה קורות לבד; כל מה ששולח, משנה או מוחק משהו שואל אותי קודם. מחיקה לצמיתות פשוט לא זמינה לו
- זיכרון בשלושה צעדים: hook רושם כל סשן שהסתיים בכ-10 אלפיות שנייה בלי קריאה למודל, ריצה לילית קוראת את הראיות של היום ומעדכנת את הדפים המסודרים, והתוצאה היא commit אחד שאדם יכול לבדוק
- הריצה הלילית חייבת להצהיר אילו מקורות כיסתה ואילו דפים שינתה, והקוד בודק את ההצהרה לפני שהריצה נחשבת
- יומן משימות שומר סיכומים קצרים ומצונזרים של עבודה שהושלמה והופך דפוסים חוזרים להצעות עם ראיות. הוא אף פעם לא מקדם לבד skill, hook או זיכרון; אדם מאשר
- דפוס נספר רק כשהוא מופיע בשני ימים שונים, או שלוש פעמים ביום אחד
- מה שרץ בפועל תמיד שווה ל-commit מתויג, ושינויים מהפרויקט המקורי נכנסים רק דרך בקשת מיזוג שנבדקה

## מה הוא עושה לבד, ומה מחכה לי
- **לבד, בלי לחכות לי**: קריאה והכנה. למשל לסכם מה עוד פתוח מול ספק, להכין תדריך של עמוד אחד לפגישה של מחר, לשים לב להתנגשות ביומן, או לנסח תשובה בסגנון שלי.
- **שואל קודם**: כל מה ששולח, משנה או מוחק משהו. למשל לשלוח תשובה, להזיז או לבטל אירוע, לקבוע שיחה או להעביר מייל לארכיון.
- **לא זמין לו בכלל**: למחוק מייל לצמיתות, לקדם לבד skill, hook או זיכרון (הוא מציע, אדם מאשר), או לגשת לחשבון של אדם אחר.

## איך זה בנוי
אני כותב בצ׳אט פרטי בוואטסאפ או בטלגרם. הסוכן רץ כל הזמן על המחשב שלי, וקורא, מחפש, מסכם ומנסח לבד. כל מה שהיה שולח, משנה או מוחק נעצר בשער ״שואל קודם״ ומחכה ללחיצה שלי. הוא פועל במייל וביומן רק אם חיברתי חשבון, וטקסט בתוך מייל הוא בשבילו מידע, לא הוראה. לזיכרון שתי שכבות: היומן של הסוכן עצמו ב־Obsidian תחת git, ו־PersonaKit כזיכרון המשותף לכל הסוכנים שלי ולכלי הפיתוח.

## שלושה מנגנונים ששומרים עליו אמין
- **זיכרון שמוכיח את עצמו**: כל סשן שהסתיים נרשם בכ־10 אלפיות שנייה בלי קריאה למודל. ריצה לילית חייבת להצהיר אילו מקורות כיסתה ואילו דפים שינתה, הקוד בודק את זה, והתוצאה היא commit אחד שאפשר לבדוק.
- **שיפורים רק עם ראיות**: דפוס נספר רק בשני ימים שונים או שלוש פעמים ביום אחד, הופך להצעה עם ראיות, ונכנס רק אם אדם מאשר.
- **שום דבר לא יוצא בלי לחיצה**: הוא מנסח, שולח לי את הטיוטה עם כפתור, ושולח רק אחרי שלחצתי.
