# catchup

## Overview
תוסף ל-Claude Code שמסכם באנגלית פשוטה את הודעות הסוכן שלא קראת. חזרת לשרשור ארוך, או שסוכן עבד בזמן שלא היית, ובמקום לגלול אתה מבקש סיכום: מה הסוכן צריך ממך, מה הוא עשה ועם איזו הוכחה, ומסירה לסשן הבא. הכלל שמאחוריו הוא כלל שאני משתמש בו בכל מקום: המודל כותב שפה, הקוד עושה את השאר.

## Technical Details
- **Language**: TypeScript
- **Platform**: תוסף ל-Claude Code, מותקן מה-plugin marketplace
- **Model**: רץ בסשן ה-Claude שלך
- **License**: MIT

## יכולות עיקריות
- המודל חייב להחזיר JSON מובנה. הקוד מאמת אותו, מנסה שוב פעם אחת אם הוא לא תקין, ואם לא הצליח מציג את הטקסט הגולמי עם אזהרה
- כל פריט מפנה להודעה שממנה הגיע
- פריט "בוצע" בלי הוכחה מוצג כלא נבדק, ושם שלא מופיע בהודעות מסומן כלא ודאי
- שרשורים ארוכים מסוכמים בחלקים ואז ממוזגים
- סודות וכתובות אימייל מוסתרים לפני שמשהו מגיע למודל, ושום דבר לא נשמר: המצב חי בזיכרון בלבד
- בדיקת השחרור נכשלת אם מופיעה בקוד קריאה לאחסון, לרשת או לתהליך

## מה המודל עושה, ומה הקוד
- **המודל** מנסח את הסיכום במשפטים קצרים ומוצא שאלות שמחכות לכם.
- **הקוד** בודק את אורך המשפטים, משלים שאלות שהמודל פספס, קובע מה נכשל ומה עוד רץ, מחליט אם ״בוצע״ באמת הוכח, ובודק שכל מספר הודעה וכל שם באמת קיימים.
- **אף אחד מהם** לא שומר כלום ולא פונה לרשת. בדיקת השחרור נכשלת אם מופיעה בקוד קריאה לאחסון, לרשת או להפעלת תהליך.

## איך זה בנוי
ההודעות של הסוכן שלא קראתם (והודעות מסשנים אחרים) עוברות ניקוי של סודות וכתובות מייל, מתחלקות לחלקים אם השרשור ארוך, ועוברות למודל, שמחזיר מבנה JSON קבוע. הקוד בודק כל פריט ומציג את חלונית הסיכום בצד, תמיד באותו סדר ובאותן כותרות, בלי להוסיף תור לשיחה.
